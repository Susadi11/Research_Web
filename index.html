Core Components

Four Integrated AI Modules

Each module addresses a critical aspect of dementia detection and care, working together as a unified multimodal platform.

Emotion-Aware Conversational AI

Fine-tuned LLaMA 3.2 3B with LoRA provides empathetic support while analyzing 12 cognitive parameters across text, audio, and temporal modalities. Crisis detection layer triggers immediate alerts for high-risk phrases.

LLaMA 3.2 3B XGBoost BERT Whisper ASR

Gamified Cognitive Stimulation

Memory-based card matching tasks measure reaction time, accuracy, and cognitive features (SAC, IES). Motor baseline calibration isolates cognitive processing time. LSTM temporal model detects gradual cognitive decline.

LSTM SAC / IES Logistic Regression

Voice-Based MMSE Screening

Automated Mini-Mental State Examination using multimodal fusion of audio features (MFCCs, Chroma, Tonnetz) and TF-IDF text features. Achieves 90.70% accuracy without requiring clinician contact.

Random Forest XGBoost Librosa PCA

Context-Aware Smart Reminders

Adaptive reminder system with BERT-based NER for parsing, behavioral learning over 30-day rolling logs, real-time WebSocket alarm escalation, and automatic caregiver notification on confusion detection.

BERT NER Gradient Boosting WebSocket
System Architecture

Three-Tier Distributed Architecture

A modular, scalable design separating user interaction, intelligence, and clinical oversight across three distinct layers.

1
Mobile Client (Kotlin Multiplatform)
Jetpack Compose + MVVM for Android, iOS & Web. Hosts conversational AI, games, MMSE & reminders.
2
Cloud Backend Intelligence Layer
Manages auth, ML inference, dementia risk estimation & adaptive scheduling. MongoDB Atlas for multimodal data.
3
Caregiver Web Dashboard
Single-page application visualising longitudinal risk scores, cognitive trends, MMSE results & alerts.
