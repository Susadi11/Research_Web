Step 1

Literature Survey

Dementia affects nearly 55 million people worldwide with 10 million new cases annually. We reviewed existing work across conversational AI, gamified cognition, automated assessment, and smart reminders — identifying critical limitations in each area.

Conversational AI [5,6,7,8]
Chatbots & Speech-Based Dementia Care
Existing conversational AI systems lack evidence-based content, have restricted scope, and do not track cognitive symptoms. Speech-based approaches show linguistic features reliably differentiate dementia from healthy controls, but remain optimised for episodic screening rather than continuous adaptive monitoring.
Gamified Cognition [9,10]
Game-Based Cognitive Stimulation
Memory skill games improve recall in elderly users; interactive systems support attention across all dementia stages. However, these approaches operate in isolation without integration into longitudinal risk monitoring pipelines.
MMSE Automation [11,12]
Automated Cognitive Assessment
Automated MMSE scoring increases accessibility for community-based detection. Voice-based digital tools enable practical scoring without clinician contact. Current methods provide only snapshot assessments — not continuous monitoring.
Smart Reminders [13,14,15]
Medication & Cognitive Reminders
Smart reminder systems improve adherence in mild dementia patients. Voice familiarity enhances engagement. AI-powered apps support caregiver oversight. Temporal anomaly detection highlights clinical relevance of shifts in verbal patterns.
Step 2

Research Gap

Identified Gaps in Existing Work
✕
Existing approaches remain largely isolated — lacking integration across modalities or longitudinal monitoring pipelines.
✕
Conventional monitoring uses long intervals between clinical assessments, missing gradual cognitive decline in daily life.
✕
Conversational AI systems fail to adapt to evolving emotional and cognitive needs and provide no risk tracking mechanism.
✕
No unified platform combines conversational support, gamified assessment, automated MMSE, and adaptive reminders into a continuously monitored system.
✕
The stigma of cognitive testing discourages frequent clinical visits, leaving many elderly people — especially those living independently — without early detection.
Step 3

Research Problem

How can a multimodal, AI-driven platform continuously monitor cognitive decline indicators in elderly individuals through naturalistic daily interactions — providing early dementia risk detection, empathetic conversational support, and proactive caregiver alerts — without requiring intrusive clinical assessments?

Step 4

Research Objectives

1
Develop an emotion-aware conversational AI using a fine-tuned LLaMA 3.2 3B model that analyzes 12 cognitive parameters from text, audio, and temporal features to estimate dementia risk in real time.
2
Design a gamified cognitive stimulation module with motor-baseline-calibrated reaction-time measurement, LSTM-based temporal decline detection, and dementia risk classification from gameplay features.
3
Build a fully voice-based automated MMSE screening system using multimodal audio-text fusion, achieving accurate cognitive level classification without requiring clinician contact.
4
Implement a context-aware adaptive reminder system that monitors adherence, detects confusion via behavioral profiling, and escalates real-time caregiver alerts through WebSocket delivery.
5
Integrate all modules into a three-tier distributed platform (Kotlin Multiplatform mobile, cloud backend, web dashboard) enabling longitudinal cognitive monitoring with a weekly fused risk score achieving ROC-AUC ≥ 0.90.
Step 5

Methodology

Dataset & Preprocessing
DementiaBank Pitt Corpus — transcribed speech
Mental Health Counselling Conversations — chatbot fine-tuning
ADNI dataset — cognitive game calibration
SpaCy tokenisation, POS tagging, BERT embeddings
Librosa / FFmpeg for acoustic feature extraction
Conversational AI Module
LLaMA 3.2 3B Instruct + LoRA fine-tuning
12-parameter cognitive scoring (0–36 scale)
BERT + XGBoost text model (87.27%)
Multimodal XGBoost fusion (89.06%)
Weekly risk score with WEI progression tracking
Cognitive Game Module
Memory card matching with reaction-time logging
Motor baseline calibration via tap test
SAC & IES feature derivation
LSTM temporal decline detection (72.21%)
Logistic Regression risk classifier (96.17%)
MMSE Screening Module
MFCCs, Chroma, Tonnetz, Spectral Contrast features
TF-IDF + PCA for text feature reduction
XGBoost audio model + Random Forest text model
Late fusion (P_final = average of both probabilities)
4-level cognitive classification (Normal → Severe)
Smart Reminder Module
BERT-based NER (dslim/bert-NER) for task parsing
Gradient Boosting risk scoring on 17 behavioral traits
30-day rolling log for adaptive scheduling
WebSocket real-time alarm delivery & escalation
Confusion detection at 96.51%, caregiver alerts at 96.05%
Multimodal Weekly Fusion
Aggregate session scores from all 4 modules
Weekly base score normalised to 0–100
WEI captures temporal progression
5 risk levels: Normal → Critical
Fused ROC-AUC of 0.94 (3–5 pts above individual modules)
