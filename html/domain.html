Step 1

Literature Survey

Dementia affects nearly 55 million people worldwide with 10 million new cases annually. We reviewed existing work across conversational AI, gamified cognition, automated assessment, and smart reminders to identify critical limitations in each domain.

Conversational AI & Speech Analysis
References [5, 6, 7, 8]
[5]
AI Chatbots for Dementia Support
Conversational agents deployed for elderly companionship lack clinical grounding and cannot track cognitive symptom progression over time.
[6]
Linguistic Biomarkers in Dementia Speech
Analysis of DementiaBank transcripts reveals that pause frequency, lexical diversity (TTR), and semantic coherence reliably distinguish dementia from controls with >80% accuracy.
[7]
Multimodal Speech-Text Fusion for Screening
Combining acoustic features (MFCCs, prosody) with text embeddings improves classification accuracy but is optimised for single-episode screening, not continuous longitudinal use.
[8]
Emotion-Aware Dialogue Systems
LLM-based agents with emotional context improve elderly user engagement, but none integrate dementia-specific risk parameter frameworks or caregiver alert pipelines.
Gap Identified: No system combines continuous speech monitoring with real-time cognitive risk tracking and caregiver alerting in a unified pipeline.
Gamified Cognitive Stimulation
References [9, 10]
[9]
Memory Games for Cognitive Rehabilitation
Memory card matching and pattern recall games administered digitally show measurable improvement in short-term recall scores over 8-week intervention periods in mild-to-moderate dementia cohorts.
[10]
Reaction Time as a Cognitive Biomarker
Motor baseline calibration in interactive tasks allows detection of statistically significant reaction time elongation as an early indicator of cognitive decline, validated against MMSE gold standard.
Gap Identified: Gamified approaches operate in isolation; none feed gameplay performance features into longitudinal dementia risk scoring models.
Automated MMSE & Cognitive Assessment
References [11, 12]
[11]
Voice-Based Automated MMSE Scoring
Digital voice tools automate administration of the 30-point MMSE battery, achieving clinician-comparable scoring accuracy without requiring physical contact — improving community-based access in rural and low-resource settings.
[12]
Multimodal Fusion for Cognitive Level Classification
Combining acoustic features (MFCCs, chroma, spectral centroid) with TF-IDF text vectors and PCA dimensionality reduction enables 4-level cognitive classification (Normal / MCI / Moderate / Severe) outperforming unimodal baselines.
Gap Identified: Existing tools provide point-in-time snapshots only; none track MMSE trajectories continuously or link results to adaptive intervention triggers.
Smart Reminder & Behavioural Monitoring Systems
References [13, 14, 15]
[13]
AI-Powered Medication Adherence Systems
Intelligent reminder apps with voice familiarity features significantly improve medication adherence rates in mild dementia patients, reducing missed-dose incidents by up to 34% versus passive notification systems.
[14]
Behavioural Anomaly Detection in Reminder Responses
Temporal pattern analysis of reminder interaction logs (response latency, repetitive queries, missed acknowledgements) identifies confusion events with clinical significance, alerting caregivers in time-sensitive scenarios.
[15]
Caregiver Oversight via Smart Platforms
Web dashboard-based caregiver tools with real-time patient activity feeds increase caregiver confidence and reduce emergency interventions, but lack integration with broader cognitive risk monitoring pipelines.
Gap Identified: No existing reminder system uses behavioural profiling to classify confusion risk levels or deliver real-time WebSocket-based caregiver escalation alerts.
Step 2

Research Gap

Existing approaches remain largely isolated, lacking integration across modalities or longitudinal monitoring pipelines.
Conventional monitoring relies on infrequent clinical assessments, missing gradual cognitive decline in everyday daily life.
Conversational AI systems fail to adapt to evolving emotional and cognitive needs and provide no risk tracking mechanism.
No unified platform combines conversational support, gamified assessment, automated MMSE, and adaptive reminders into a continuously monitored system.
The stigma of cognitive testing discourages frequent clinical visits, leaving elderly individuals living independently without early detection support.
Step 3

Research Problem

How can a multimodal AI driven platform continuously monitor cognitive decline indicators in elderly individuals through naturalistic daily interactions — providing early dementia risk detection, empathetic conversational support, and proactive caregiver alerts — without requiring intrusive clinical assessments?

Step 4

Research Objectives

01
Develop an emotion aware conversational AI using a fine tuned LLaMA 3.2 3B model that analyses 12 cognitive parameters from text, audio, and temporal features to estimate dementia risk in real time.
02
Design a gamified cognitive stimulation module with motor baseline calibrated reaction time measurement, LSTM based temporal decline detection, and dementia risk classification from gameplay features.
03
Build a fully voice based automated MMSE screening system using multimodal audio text fusion, achieving accurate cognitive level classification without requiring clinician contact.
04
Implement a context aware adaptive reminder system that monitors adherence, detects confusion via behavioural profiling, and escalates real time caregiver alerts through WebSocket delivery.
05
Integrate all modules into a three tier distributed platform (Kotlin Multiplatform mobile, cloud backend, web dashboard) enabling longitudinal cognitive monitoring with a weekly fused risk score achieving ROC-AUC of 0.94.
Step 5

Methodology

A five-stage research pipeline — spanning data collection, module-level AI development, multimodal feature fusion, and integrated risk scoring — underpins the Hale platform. Each module targets a distinct cognitive assessment modality and contributes a weighted sub-score to the unified Weekly Estimated Index (WEI).

00
Dataset & Preprocessing
Multi-source clinical and behavioural corpora
Foundation

Three curated datasets power the training pipeline: the DementiaBank Pitt Corpus (dementia / healthy speech transcripts), the Mental Health Counselling Conversations dataset (emotion and sentiment patterns), and the ADNI dataset (longitudinal neuroimaging and cognitive scores). Audio signals are processed via Librosa (MFCCs, chroma, spectral centroid) and FFmpeg (resampling, noise reduction). Text is tokenised with SpaCy and embedded using BERT base uncased. Class imbalance is corrected with SMOTE oversampling.

Datasets

  • Mental Health Conversations
  • ADNI (Neuroimaging)
Preprocessing Tools

  • FFmpeg — Audio resampling & denoising
  • SpaCy — NLP tokenisation & NER
  • BERT — Sentence embeddings
  • SMOTE — Class rebalancing
Feature Types

01
Conversational AI Module
LLaMA 3.2 3B Instruct — LoRA Fine-tuned
89.06%

A LLaMA 3.2 3B Instruct model fine-tuned via LoRA (Low-Rank Adaptation) conducts empathetic dialogues while simultaneously extracting 12 cognitive parameters per session (lexical diversity TTR, semantic coherence, pause frequency, repetition rate, sentiment drift, topic maintenance, response latency, word-finding pauses, syntax complexity, emotional tone, question comprehension, and task completion). A BERT + XGBoost classifier achieves 87.27% accuracy on text features alone; late fusion with Whisper ASR audio features raises multimodal accuracy to 89.06%. Risk is tracked via a Weighted Estimated Index (WEI) across sessions to detect longitudinal decline.

Pipeline Steps
  1. Voice input → Whisper ASR transcription
  2. 12-parameter extraction (NLP + acoustic)
  3. BERT embedding + XGBoost classification
  4. Multimodal late fusion (text + audio)
  5. WEI session risk score computation
  6. Crisis alert trigger via threshold breach
Models & Techniques
  • LLaMA 3.2 3B + LoRA (r=16, α=32)
  • Whisper ASR — speech-to-text
  • BERT base uncased — text embeddings
  • XGBoost — risk classification
  • Multimodal late fusion strategy
  • SMOTE — training data balancing
Results
  • Text-only accuracy: 87.27%
  • Multimodal accuracy: 89.06%
  • F1 Score: 0.88
  • 12 cognitive parameters tracked
  • WEI longitudinal risk trending
02
Cognitive Game Module
LSTM Temporal Decline Detection · Memory Card Matching
96.17%

A gamified memory card-matching task with motor baseline calibration captures reaction time, accuracy, and engagement across game sessions. Two engineered feature groups — SAC (Session Accuracy Change) and IES (Inverse Efficiency Score) — quantify performance decline over time. An LSTM network trained on sequential gameplay sessions detects temporal cognitive decline patterns (72.21% accuracy). A subsequent risk classifier (XGBoost, Random Forest ensemble) maps gameplay features to 3-class dementia risk levels, achieving 96.17% classification accuracy.

Pipeline Steps
  1. Motor baseline calibration session
  2. Memory card gameplay (timed trials)
  3. SAC + IES feature extraction
  4. LSTM sequence modelling (decline)
  5. Risk classification (3-class output)
  6. Session sub-score → WEI contribution
Models & Techniques
  • LSTM — temporal sequence modelling
  • XGBoost + Random Forest ensemble
  • Motor baseline calibration protocol
  • SAC (Session Accuracy Change)
  • IES (Inverse Efficiency Score)
Results
  • LSTM decline detection: 72.21%
  • Risk classification: 96.17%
  • 3-class risk output: Low / Moderate / High
  • Baseline-normalised scoring
03
MMSE Screening Module
Automated Voice-Based Cognitive Level Classification
90.70%

A fully voice-driven automated MMSE administers 30-point assessments without clinician contact. Audio responses are processed to extract 13 MFCCs, chroma, and spectral centroid features via Librosa. Text responses are vectorised using TF-IDF with PCA dimensionality reduction. A late fusion strategy combines audio and text predictions from separate XGBoost and Random Forest classifiers, achieving a 4-level cognitive classification (Normal / MCI / Moderate Impairment / Severe Impairment) at 90.70% accuracy.

Pipeline Steps
  1. Voice question administration
  2. Whisper ASR transcription
  3. Audio: MFCC + Chroma + Spectral
  4. Text: TF-IDF vectorisation + PCA
  5. Separate audio & text classifiers
  6. Late fusion → 4-level MMSE score
Models & Techniques
  • XGBoost — audio classification
  • Random Forest — text classification
  • Librosa — acoustic feature extraction
  • TF-IDF + PCA — text representation
  • Late fusion ensemble strategy
Results
  • Automated MMSE accuracy: 90.70%
  • 4-class output: Normal → Severe
  • Audio F1: 0.89
  • Text F1: 0.87
  • Fused F1: 0.91
04
Smart Reminder Module
Adaptive Scheduling · Confusion Detection · WebSocket Alerts
96.51%

A context-aware reminder system integrates BERT-based Named Entity Recognition (NER) to parse medication and appointment information from natural language. A Gradient Boosting classifier trained on 17 behavioural traits (response latency, repetition frequency, missed acknowledgements, temporal shift indicators, etc.) from a 30-day rolling behavioural log detects confusion events in real time, achieving 96.51% detection accuracy. Detected confusion events trigger immediate WebSocket-based caregiver alerts with contextual patient status delivered to the React web dashboard.

Pipeline Steps
  1. NLP parsing via BERT NER
  2. Adaptive reminder scheduling
  3. 30-day behavioural log collection
  4. 17-trait feature extraction
  5. Gradient Boosting confusion detection
  6. WebSocket real-time caregiver alert
Models & Techniques
  • BERT NER (dslim/bert-NER)
  • Gradient Boosting — confusion detection
  • 30-day rolling behavioural log
  • 17 engineered behavioural features
  • WebSocket real-time push alerts
  • Logistic Regression baseline comparison
Results
  • Confusion detection: 96.51%
  • Alert delivery latency: <1.2s
  • 17 behavioural traits profiled
  • Caregiver alert accuracy: 96.05%
05
Multimodal Weekly Risk Fusion
Integrated WEI Score · 5-Level Risk Classification
ROC 0.94

The four module sub-scores are aggregated weekly into a single Weighted Estimated Index (WEI) normalised to a 0–100 scale. Each module weight reflects its clinical contribution: Conversational AI (35%), MMSE (30%), Game Performance (20%), Reminder Behaviour (15%). A 5-level risk classification (Minimal / Low / Moderate / High / Critical) is applied to the WEI, with the caregiver dashboard updated in real time. The overall system achieves a ROC-AUC of 0.94.

Fusion Weights
  • Conversational AI — 35%
  • MMSE Screening — 30%
  • Cognitive Game — 20%
  • Smart Reminders — 15%
Risk Levels
  • WEI 0–20: Minimal Risk
  • WEI 21–40: Low Risk
  • WEI 41–60: Moderate Risk
  • WEI 61–80: High Risk
  • WEI 81–100: Critical Risk
System Performance
  • Overall ROC-AUC: 0.94
  • Multimodal accuracy: 89.06%
  • Weekly WEI score (0–100 scale)
  • Real-time dashboard push
  • Longitudinal trend visualisation
